# opskit-fixes
Some basic fixes for the various quirks of `github.com/growlf/opskit`.

Rather than cloning these files all at once, grab the ones you like and overwrite them in your opskit install.

I recommend using my install.sh file, rather than the standard one, which is currently broken.

If this process is inconvenient for you, open issues in the main branch (found at `github.com/growlf/opskit`)
